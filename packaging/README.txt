Click2Whoosh — use the Zwift Click v2 with MyWhoosh on a Mac

INSTALL
1. Drag Click2Whoosh into the Applications folder.
2. Open it with a double click. The first time, macOS says it cannot verify the developer
   (the app is not notarized by Apple): press "Done".
3. Open System Settings → Privacy & Security, scroll down to the message about Click2Whoosh
   and press "Open Anyway", then confirm with your password.
   You only need to do this the first time.

A bicycle appears at the top right, in the menu bar: that is Click2Whoosh.
There is no window and no Dock icon.

FIRST LAUNCH
The "Welcome to Click2Whoosh" window opens and guides you step by step:
1. Permissions: press "Allow" for Bluetooth, Local Network and Accessibility and answer yes
   to the macOS requests. For Accessibility, System Settings opens: turn on Click2Whoosh in
   the list and come back to the window.
2. Click: press any button on the Click, it connects within a few seconds.
3. MyWhoosh: Connections → OpenBikeControl icon at the top right → Click2Whoosh → Yes.
   BikeControl must be closed.
4. What the buttons do, the menu and the settings.
The checkmarks turn green by themselves. You can reopen the guide from the bicycle menu:
"Getting Started…".

To change what each button does: bicycle menu → Settings…
To start it automatically at login: bicycle menu → Launch at Login.

IF SOMETHING IS WRONG
- The Click does not connect: System Settings → Privacy & Security → Bluetooth, check that
  Click2Whoosh is on. Close BikeControl and the Zwift app.
- MyWhoosh does not see Click2Whoosh: Privacy & Security → Local Network, turn on
  Click2Whoosh; the Mac and MyWhoosh must be on the same network.
- Music (button Y) does not work: Privacy & Security → Accessibility, turn on Click2Whoosh.
  If it is already there but does not work (it happens after an update), remove it with − and add it again.
- Log of what happens: bicycle menu → Open Log.
- Do not update the Click's firmware: it could change the protocol.

The app speaks English or Italian, following the language of your Mac.
